# Rox Quick Commands

Pre-built commands for common tasks. Just say these and Rox will execute them instantly.

## App Launchers
```
open youtube
open spotify
open terminal
open vscode
open notes
open safari
open chrome
open slack
open discord
```

## YouTube Commands
```
yt status              # Check YouTube agent status
yt jobs                # List active YouTube jobs
yt dashboard           # Open YouTube dashboard
```

## Search & Info
```
search for React tutorials
weather in San Francisco
time                   # Get current time
```

## Spotify Commands
```
spotify play           # Resume playback
spotify pause          # Pause playback
spotify next           # Skip to next track
spotify prev           # Go to previous track
spotify now            # Show current track
```

## System
```
status                 # Check Rox status
help                   # Show all commands
?                      # Show help
```

## Examples
- "open youtube" → Opens YouTube in browser
- "search for TypeScript tips" → Searches the web
- "weather in London" → Gets weather for London
- "spotify now" → Shows what's currently playing
